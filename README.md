# Relief Bridge

## Open and share the website

Open **[Relief Bridge](https://chilicheesedog.github.io/relief-bridge/)** in your browser:

https://chilicheesedog.github.io/relief-bridge/

Share this same link with anyone testing the website. No account, installation, terminal, or running computer is needed. The link stays available while this repository and its GitHub Pages publishing remain enabled.

The public website is an interactive demonstration. Each browser saves its own test records; records are not shared between visitors or devices. Use fictional clinic and donor details when testing.

## Request medical supplies

1. Open **Requests** and select **New request**, or select **Request supplies** on the overview.
2. Enter the clinic name, city, state, supply, and quantity.
3. Choose a priority and enter any coordination requirements.
4. Select **Submit request**.

Enter a whole-number quantity between 1 and 100,000. The quantity field shows the unit for the selected supply.

## Offer supplies

1. Open **Supply inventory** and select **Offer supplies**.
2. Enter the donor organization, city, state, supply, and quantity.
3. Select **Add supply donation**.

The donation becomes available for requests that need the same supply.

## Match supplies to a clinic

1. Open a request and select **Review matches**.
2. Review the clinic requirements and compatible donations.
3. Select a donor. Donations in the same state appear first.
4. Enter the allocation quantity and select **Allocate supplies**.

Allocations reserve stock immediately. You cannot allocate more than the available stock or the request's remaining need.

## Track a shipment

1. Open **Shipments**.
2. Select **Dispatch shipment** to move an allocation to **In transit**.
3. Select **Confirm delivery** to move it to **Delivered**.

These actions record demonstration statuses; they do not arrange real transportation.

## Search and filter

Use the search field to find clinics, donors, or supplies. Use the state and priority filters to narrow requests. Select **Clear filters** when no matching requests appear to restore the full list.

## Save and repeat a test

Changes save automatically in the current browser. Reload the website to continue with those records. Keep browser storage enabled to retain changes between visits. Select **Reset demo data** at the top of the website to restore the original examples. This removes your saved demonstration records in this browser.

To test the complete workflow, create a request, offer the same supply, allocate a match, dispatch the shipment, confirm delivery, and reload the page. Try the navigation and filters on a phone as well.

## Support relief efforts

Select **Support relief** or **Give to Direct Relief** to open Direct Relief's external donation page. Donations are handled on that organization's website.
